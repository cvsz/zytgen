# `@zytgen/ads-intelligence`

Typed, deterministic advertising-intelligence domain extracted from the useful concepts in
`cvsz/zadsystem`.

The package provides:

- source-backed ad records;
- a Meta Ad Library connector port;
- hook, angle, and CTA pattern analysis;
- brand-versus-competitor angle-gap analysis;
- a 20-angle creative planning catalog;
- mandatory approval and evidence flags for creative plans.

It intentionally does not provide live provider calls, simulated performance metrics, or
unsupported advertising claims.
